# 摘录 / Excerpts

用于 Obsidian 的本地 Markdown 摘录时间线。专注 **记录、阅读、查找**。

## 开发中 — 原生 Markdown 编辑入口与简化命名

- 顶部快速摘录卡片底部新增「编辑文档」：桌面端显示图标与文字、窄屏显示图标；可直接新建并打开 Obsidian 原生 Markdown 编辑器。
- 保存与编辑入口共用普通 Markdown 创建逻辑，选中的标签写入 YAML `tags`，不创建额外文件格式。
- 新文件命名仅取用户明确写入的 Markdown H1；没有 H1 时使用设备本地时间（如 `摘录 2026-10-24 10-14.md`），重名自动追加数字后缀。
- 通过编辑入口新建的空白文档，关闭编辑页面后若仍没有正文且初始属性未变，则使用 Obsidian 文件回收机制清理。仅切换标签页不清理；编辑后的文档和重命名文档始终保留。

## beta.15 — 保存当前筛选为摘录页

- 「最近摘录」工具栏右侧新增页面级更多菜单，可保存当前标签与关键词筛选；无筛选时禁用保存。
- 使用原生风格弹窗输入页面名称，验证重名与非法名称，自动生成同目录的 `名称.excerpts`，不会复制任何 Markdown。
- 已保存页面重新打开时恢复标签与搜索词；临时修改不会写入文件，只有「更新当前页面」才保存。
- 「首页.excerpts」继续是默认首页，打开其他摘录页不会改变默认入口；插件设置可直接打开已保存的摘录页。
- 保持顶部摘录卡片、时间线和卡片底部操作不变。

## beta.14 — 浮墨式顶部快速记录卡片

- 顶部输入区重建为单一轻量卡片，正文与底部工具栏分层，不提供多余标题或展开控件。
- 桌面输入卡片内边距：上 16px / 左右 20px / 下 12px；窄视图上 14px / 左右 14px / 下 10px。
- 移动端阅读流左右留白：容器宽度不超过 400px 时为 8px、401–700px 时为 12px；摘录卡片左右内边距均为 14px，保留原有桌面布局。
- 正文三行初始书写空间，桌面最小 84px / 最大 320px，窄分栏最小 78px / 最大 min(240px,34dvh)，无内部边框与阴影。
- 底部标签为 22px 可见高度的微型胶囊，取消常驻删除 ×；点击标签进入已有选择器管理，单行过多以 +N 收纳。
- 保存按钮始终位于右下角，空正文禁用；聚焦正文收起标签面板，保留标签草稿。
- 新增浅/深主题、320/390/768/1280px、默认输入与标签展开状态的测试截图和几何检查。

## beta.13 — 标签编辑与输入交互修正

- 卡片标签编辑采用草稿式多选：只有点击「完成」才一次性写入 YAML；点击「取消」或按 Escape 不更改文件。
- 顶部标签面板可使用标签按钮或 Escape 收起，已选草稿标签保留，输入框清空按钮只清除查询。
- 标签搜索统一为低对比单层输入表面，候选项改为列表行；标签展示仍是 22px 视觉微型胶囊。
- 标签选择过程中复用同一个输入节点，避免连续输入、光标与中文输入法状态丢失。
- Markdown 正文内标签保留为只读，提供「编辑原文」入口；保存时拒绝覆盖编辑期间的外部标签修改。

## beta.12 — Editorial Feed 界面重构

- 日期分组阅读流：桌面日期轨道、移动端顶部日期标题；窄分栏自动切换。
- 顶部记录框始终直接可输入，标签选择按需展开，右下角保存。
- 卡片内容按 Markdown 自然呈现；来源、批注、变种等 H2 统一为可展开章节行。
- 微型标签胶囊（可见约 22px）放在卡片底部左侧；更多菜单位于底部右侧。标签超出一行后出现 `+N`，可展开与收起。
- 纯文本长正文提供预览与完整展开；独立媒体开头的摘录使用媒体优先排版，播放器和复杂 Markdown 不作危险裁切。
- 每批 40 条按需渲染；加载更多时增量添加，已显示卡片不再整体替换。
- 「编辑原文」与「编辑分组」仍从原生 Obsidian 菜单跳转 Markdown 源文件，不提供卡片内正文编辑器。
- 沿用 Obsidian 主题色、字体与圆角，不新增数据模型或迁移要求。

## 安装

将构建得到的 `main.js`、`manifest.json` 和 `styles.css` 放入 Vault 的 `.obsidian/plugins/excerpts/`，在社区插件中启用。

在插件设置中填写一个现有或新的文件夹，点击“创建并打开”。这会创建空白的 `首页.excerpts`；以后可直接通过 Obsidian 文件管理器打开。侧边栏图标与命令面板始终打开默认首页，已保存的筛选页可通过文件管理器或插件设置打开。

```text
摘录/
  首页.excerpts
  文学摘录.excerpts
  时间与生活.md
  文学摘录.md
  图片.png
```

`首页.excerpts` 是默认入口，不保存摘录内容。使用时间线右侧的「页面选项 → 保存当前筛选…」会创建可复用的筛选页（例如 `文学摘录.excerpts`）；它仅保存 `version: 1` 及 `filter.tag` / `filter.query` 配置，普通 Markdown 文件仍是唯一摘录数据。标签使用原生 YAML 属性，附件遵循原生路径。若需要调整扫描范围，可在设置中切换是否包含子文件夹。

## 文件命名

新建 Markdown 文件时，仅在明确存在 H1 标题的情况下使用该标题作为文件名；其他情况统一使用设备本地时间。名称进行基本非法字符清理和长度限制；重名时追加 `-2`、`-3` 等后缀，不覆盖现有文件。创建后文件名不会随着正文编辑自动改变，需要修改时使用 Obsidian 原生重命名。
