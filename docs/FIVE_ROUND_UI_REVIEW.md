# Excerpts — 五轮 UI 迭代记录

实施版本：**0.2.0-beta.3**。本轮聚焦 Obsidian 原生设计、flomo 的低摩擦收藏，以及 Apple HIG 中的内容优先、交互可发现、键盘焦点与恢复能力。**只修改显示层、UI 测试与构建版本，不修改 Markdown 编解码或 Repository。**

## 轮次及验收

| 轮次 | 发现的问题 | 本次修改 | 自动化验证 |
|---|---|---|---|
| 1 — 主题基线 | CSS 多轮覆盖、重复声明，深浅色适配不稳定 | 收敛为单一 scoped stylesheet；颜色/字体/间距取 Obsidian tokens；保留可识别的卡片边框 | 18 数据 + 16 UI + 编译、冒烟 |
| 2 — 输入阻力 | 输入框固定高度偏大；标签/搜索与键盘退出行为不统一 | 默认两行输入、聚焦时扩展；标签和搜索可折叠且支持 Escape；补上 aria-controls 和输入名称 | 18 数据 + 17 UI |
| 3 — 阅读层级 | 窄屏顶部多个操作图标占据正文空间，日期冗长 | 小屏仅保留原生更多菜单，收藏/编辑入口仍在菜单中；短日期、文章语义、简洁附属区 | 18 数据 + 17 UI |
| 4 — 可访问性 | 卡片重绘后键盘焦点丢失；编辑快捷保存不一致 | 焦点恢复、操作状态通知、Ctrl/Cmd+Enter 作用于正文和 Extra 编辑；触控目标提升 | 18 数据 + 19 UI |
| 5 — 质量收口 | 版本/安装包易错位，状态反馈不够清晰 | 日期使用 time 元素；筛选按钮标记 aria-pressed；更多菜单加入“复制正文”；版本与 CSS 作用域校验，视觉截图复验 | 18 数据 + 21 UI + release guard |

## 视觉回归（Chromium 模拟，非真实 Obsidian 客户端）

- 320px、390px、768px、1280px 均没有页面水平溢出。
- 明暗主题测试采用与 Obsidian CSS 变量兼容的模拟环境，不等于实际 Android/iOS 渲染。
- 390px 模拟中，初始输入卡片高度约 153px；摘录卡片按内容高度排列，窄屏直接编辑操作收纳到 Obsidian `Menu`。
- 仅一条摘录的正文为主视觉；来源、变种、批注等可按需展开，不展示空分类。
- 测试输入为开发用样例，不会打包到用户 Vault 中。

## 下一阶段仍需真实客户端验收

1. Android/iOS 的真实 Obsidian 宿主图标、菜单弹出定位、软键盘以及返回手势。
2. 用户当前所安装 Obsidian 主题下的字体、边框、背景对比度和布局。
3. 显示缩放、大字体、第三方主题、窄分栏及系统无障碍工具。
4. 插件升级后已打开的收藏标签页能否恢复正确视图、保持草稿，不改变未授权文件夹。
