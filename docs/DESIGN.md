# Excerpts · Editorial Feed design specification (2026-10-24)

目标：Obsidian 主题原生 × 浮墨式低干扰摘录 × Apple 风格的内容层级与排版秩序。
此文档是当前 UI 的单一设计基线；不创建自定义皮肤，也不改变数据模型。

## 已确定的规则

1. `.excerpts` 文件仍是首页入口，每条摘录仍是同目录或指定范围的普通 Markdown 文件。
2. 桌面阅读流左侧日期轨道（88px，间隔 24px），右侧单列卡片（不超过 720px）。
   容器宽度不大于 700px 时变为顶部日期行与单列卡片。
3. 顶部添加摘录按浮墨快速记录卡片设计，**始终直接可输入**、没有多余标题。
   输入卡片是安静的内容画布：`--background-secondary` 背景、1px 极弱主题边框、16px 独立圆角；正文 textarea 透明、无内部边框/阴影。
   占位提示统一为「摘录文字，或写下想法…」，正文与占位同为至少 16px、行高 1.6，获取焦点但未输入时不隐藏提示。
   正文与底部操作分层，工具栏顺序为「标签入口 → 已选标签与 +N → 编辑文档图标 → 保存」；标签候选在工具栏下方按正常文档流展开，不遮挡文字；
   已选标签无 ×，点击微型胶囊进入标签选择器取消勾选，顶部草稿直到保存摘录才写入 Markdown。
4. 卡片依次为：Markdown 正文 → 可选正文预览展开 → H2 章节 → 可选标签编辑面板 → 底部栏。
5. **底部栏左标签右更多**。按钮处于正常文档流，绝不覆盖文字和媒体。
6. 标签视觉为 20–22px 级别的低对比微型胶囊：11–12px 字号、水平 7px、间距 5px。
   默认单行，宽度不足时显示动态 `+N`；编辑或主动展开后可以换行。
   胶囊视觉大小和移动端触控目标大小分别控制。
7. 阅读态标签仅负责筛选；底部加号打开标签编辑。**卡片编辑必须先选择、再完成；取消或 Escape 不写入文件。**
   编辑器使用无额外边框的搜索行与垂直候选列表，不采用候选胶囊；顶部创建摘录复用此选择器，但标签属于草稿，随摘录保存。
   顶部标签按钮可再次点击关闭候选面板；Escape 也只关闭面板且保留已选标签；输入框内 × 仅清除查询。
   正文中的 inline 标签只读并可跳转原文修改；YAML 属性一次性提交，检查外部并发修改。
8. `## 来源`、`## 批注`、`## 变种` 和所有 H2 都是**原生 Markdown 章节**。
   使用整行 Disclosure 展开/收起；同名章节按原顺序区分，不能生成额外存储字段。
9. 正文编辑从底部 `···` → 「编辑原文」进入 Obsidian Markdown 源码视图；
   菜单另提供各个 H2 的原文定位。
10. 搜索和全局筛选只在需要时展开。阅读流按虚拟窗口渲染，缓冲量由列表设置控制（自动或固定）；Markdown 仍按需渲染。

## 其他输入字段（快速摘录正文除外）

- **统一文字层级**：仅设置 `::placeholder` 的 `color: var(--text-normal)` 和 `opacity: .5`，真实输入值保持 100% 不透明。Placeholder 的字号与行高继承各自字段，避免光标/文字跳动。
- **列表搜索**：40px（粗指针 44px）单层弱背景 `--background-secondary`、10px 圆角、左右 12px 内边距。与列表内容列对齐，不重复放大镜；聚焦时仅使用一个主题焦点环，不同时显示第二层边框。
- **标签搜索**：顶部选择和卡片编辑复用 `TagPicker`；搜索容器 40px（粗指针 44px）、10px 圆角、左右 10px 内边距、16px 图标、图文间距 8px；清空按钮点击区桌面 32px、粗指针 44px，按钮在正常 flex 行内不可遮挡文字。选项继续为 36/44px，间隔 2px，无新增浮层。
- **筛选页名称**：保留独立可见标签、示例提示和校验信息；字段 40/44px、10px 圆角、左右 12px 内边距，标签到输入、输入到校验说明各 8px；弱边框加单层焦点环。值为建议名称时 Placeholder 本来就不可见。
- **设置页文件夹路径**：继续使用 Obsidian 原生 `Setting.addText`；仅在 `.ex-settings-root` 内控制占位层级、输入框伸缩和粗指针下至少 44px 高度与 16px 字号。狭窄时允许同一设置行内部控件折行，不覆盖其他插件设置。
- **焦点与可访问性**：搜索/标签输入的焦点环只绘制在最外层输入表面；不得因焦点改变字段几何尺寸。保留 Escape、清空、拼音 IME 与原有禁用/错误提示语义。

## 圆角、状态与主题边界

- 使用 `--ex-radius-surface`、`--ex-radius-composer`、`--ex-radius-input`、`--ex-radius-option`、`--ex-radius-pill` 分别承载阅读表面、快速摘录画布、输入、列表与胶囊形态；不要分散写死相同数值。
- 保存与标签编辑「完成」使用主题强调色胶囊；筛选标签用主题中性表面与弱强调选中态；卡片标签维持低对比微型胶囊。禁用、悬停、聚焦不能改变形状。
- 30px 筛选标签与 22px 阅读标签在触控设备上保留各自视觉尺寸，点击目标至少 44px；焦点轮廓必须可见。
- 保存筛选对话框不在 `.excerpts-root` 内，需在 `.ex-save-page-modal` 中声明相同的语义变量；普通 Obsidian 宿主控件不受插件样式影响。
- 标签折叠计数 `+N` 与标签保持同类胶囊轮廓；「添加标签」可保留幽灵操作的弱背景，避免变成正文标签。

## 内容展示边界

- 普通长段落（没有列表、链接、媒体等交互元素）可以按六行预览并展开；
  含图片/视频/复杂 Markdown 的正文保持完整渲染，避免剪断播放器或链接。
- 图片尊重自然比例，卡片预览高度上限；视频/audio 控件由 Obsidian 原生渲染。
- 代码和表格的水平滚动限制在其内容区域，整个页面不得横向溢出。
- 日期按文件创建时间，以浏览用户的本地日期分组；不新增时间元数据字段。
- 不增加全局收藏、随机、嵌套附件管理、来源对象、批注对象等冗余功能。

## 测试与验收

1. `npm run verify` 包含数据测试、DOM 测试、样式约束、组件标识符及 CSS 审批锁、编译与冒烟测试。
2. Chromium 截图/布局脚本覆盖 320 / 390 / 768 / 1280px 浅色和深色，
   卡片底部、标签编辑、H2 展开、日期轨道与输入框几何关系。
3. 模拟 Obsidian WebView 不代替真实 Android/iOS 测试；仍需验证软键盘、
   第三方主题、音视频播放、超长内容、实际 Obsidian 菜单与焦点。
4. UI 组件/页面的截图矩阵、PNG 实际读取校验、审批和未覆盖项见 [`VISUAL-QA.md`](VISUAL-QA.md)。不允许把旧的 inline editor 截图脚本视为通过标准；
   编辑行为是跳转原生 Markdown 源文件。

## 实施备注

- 标签单行溢出计数以 DOM 实际宽度测量，不按照固定标签数量裁剪。
- H2 展开只增量渲染对应章节，不重绘正文 Markdown。
- 「加载更多」只追加新一页 DOM，不替换已渲染卡片，减少滚动位置和焦点抖动。
- 视觉 CSS 只能影响 `.excerpts-root`，不能污染 Obsidian 宿主 UI。
- 卡片顶部与左右共用水平尺度，底部相对减少以补偿工具栏高度；标签视觉 22px 不等于触控高度。
- 每个垂直间距只由一个父层负责：正文段落、H2 章节、标签面板、工具栏各自独立，避免叠加 margin。
