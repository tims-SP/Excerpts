# 编辑与标签交互 v2 — 实施说明

基线：`main` 的 `v0.2.0-beta.6`；实施分支：`feature/editor-tag-v2-beta6`。本次不更改 Markdown entry schema、文件夹隔离或 Vault API 语义。

## 决策

- 主摘录正文在卡片原位编辑，不用常规 Modal。
- 已有标签始终展示为可移除胶囊；推荐与输入默认折叠。
- 仅点击“添加标签”后显示推荐，推荐取当前收藏集标签并按使用次数排序。
- 点击推荐或新建标签后保持推荐区域打开，连续添加无需反复展开；点击“完成”或按 Escape 折叠。
- 标签操作仅更新内存中的编辑会话；正文与完整标签数组一次 Vault 更新。
- 未保存的正文或标签在取消时要求显式确认。切换到另一摘录不能丢弃当前脏草稿。
- 快速记录复用相同标签交互，添加标签不会提前写入摘录文件。
- 保存中的控件暂时禁用，保存失败保留编辑内容并发出反馈。
- 中文输入法组合期间 Enter 不提交标签或摘录。

## 结构和状态

- `parseTags` 统一处理逗号、中文逗号、首部 #、空白和重复标签；存储仍是 `string[]`。
- `makeTagEditor` 暴露 `read`、`draftValue`、`setValue`、`setExpanded` 和 `setDisabled`。
- 标签输入和正文输入都写入现有 `quoteDrafts` / `DraftRepository` 路径，独立草稿恢复的实现保持兼容。
- 版本冲突由已有基线比较以及 `EntryRepository.update` 二次确认，禁止覆盖外部修改。

## 自动回归验收

1. 标签推荐默认隐藏，点击添加后展开。
2. 选择已有标签、输入新标签、连续添加、胶囊移除、完成折叠。
3. 正文编辑时只出现编辑态标签；保存后正文和标签同时持久化。
4. 快速记录添加标签不会预先创建文件，单次保存完成写入。
5. Ctrl/Cmd + Enter、IME composition 不应误保存。
6. 草稿刷新/重启恢复、取消明确确认、阻止脏编辑会话静默切换。
7. CSS 继承 Obsidian tokens，触屏交互尺寸至少 44px。

## 手动验收范围

- Obsidian Android / iOS 的输入法高度变化、滚动位置、标签面板展开折叠与触控。
- 桌面 Obsidian 默认深色/浅色主题，以及至少一种第三方主题。
- 窄分栏和 320 / 390 / 768 / 1280px 容器，长正文、多标签和大字模式。

DOM 和浏览器模拟测试不代表真实移动 Obsidian 客户端验收。
